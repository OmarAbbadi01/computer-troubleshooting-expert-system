# نظام خبير لتشخيص أعطال الحاسوب

نظام خبير يعمل من سطر الأوامر بلغة Python لتشخيص مشاكل الحاسوب المختلفة.

## الميزات

- يسأل المستخدم أسئلة نعم/لا لجمع الحقائق
- يستخدم قواعد IF-THEN والاستدلال الأمامي للاستنتاج
- يعرض التشخيص والتعليل والتوصية باللغة العربية

## طريقة التشغيل

```bash
python3 main.py
```

## هيكل المشروع

| الملف | الوصف |
|-------|-------|
| `main.py` | نقطة الدخول الرئيسية وواجهة المستخدم |
| `engine.py` | محرك الاستدلال الأمامي |
| `questionnaire.py` | جمع الأسئلة وتحويل الإجابات إلى حقائق |
| `knowledge_base.py` | تحميل وتحقق من قاعدة المعرفة |
| `models.py` | هياكل البيانات المستخدمة |
| `data/knowledge_base.json` | قواعد المعرفة (34 قاعدة IF-THEN) |
| `data/questions.json` | الأسئلة والمشاكل الرئيسية |
| `evaluation/` | حالات الاختبار |

## الآلية

1. يختار المستخدم نوع الحاسوب (مكتبي أو محمول)
2. يختار المشكلة الرئيسية من القائمة
3. يجيب عن أسئلة التشخيص relevant
4. يقوم النظام باستنتاج الحقائق واستخدام محرك الاستدلال
5. يعرض النتيجة مع التعليل والتوصية
